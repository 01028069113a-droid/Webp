10. 리터럴 표기 방식으로 작성된 다음 `box` 객체가 있다. javascript let box = { color: "red", size: 10, amount: 0, fill : function() { this.amount += 2; }, consume : function() { this.amount -= 2; } }; (1) `box` 객체를 `new Object()`를 이용하는 방법으로 다시 작성하라. 정답: javascript let box = new Object(); box.color = "red"; box.size = 10; box.amount = 0; box.fill = function() { this.amount += 2; }; box.consume = function() { this.amount -= 2; }; (2) 다음 주석에 지정된 대로 자바스크립트 코드를 작성하라. // box 객체의 fill() 메서드 호출 // document.write()로 amount 프로퍼티 값 출력 // box 객체의 consume() 메서드 호출 // document.write()로 amount 프로퍼티 값 출력 box.fill(); document.write(box.amount); box.consume(); document.write(box.amount); 풀이 과정:두 번째 사진 10번 문제에서 box 객체의 초기 amount 값은 0으로 설정되어 있습니다. fill() 메서드가 실행되면 this.amount += 2가 되어 amount는 2가 됩니다. 따라서 첫 번째 document.write(box.amount)는 2를 출력합니다. 이어서 consume() 메서드가 실행되면 this.amount -= 2가 되어 amount는 다시 0(2 - 2)이 됩니다. 따라서 두 번째 document.write(box.amount)는 0을 출력합니다.
