9. 다음 코드에서 지역변수와 블록 변수 그리고 전역변수를 찾아 나열하라. (1) javascript let x; function f() { let y = x + 5; z = y + 5; return z; } 풀이 과정 전역변수: 함수 바깥에 선언된 `x`, 그리고 키워드 없이 선언되어 자동으로 전역 객체의 프로퍼티가 되는 `z` 지역변수: 함수 `f()` 내부에서 `let`으로 선언된 `y` 블록 변수: 없음 (또는 `y`가 함수 블록 내 스코프) 정답: 전역변수: `x`, `z` 지역변수: `y` 블록 변수: 없음 (2) javascript sum = 0; function f() { let x = 1; for(let n=0; n<5; n++) sum += x; } 풀이 과정 전역변수: 함수 바깥에 선언된 sum 지역변수: 함수 `f()` 내부에 선언된 x 블록 변수: for 문 블록 내에서 let으로 선언된 n 정답 전역변수:sum 지역변수: x 블록 변수: n ---
