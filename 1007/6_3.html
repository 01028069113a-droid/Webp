3. 다음 중 리터럴이 아닌 것을 찾아라. 0, 12.34, "a", 0xff, ff, null, false, "hello", 4+5 풀이 과정:리터럴(Literal)은 코드에 직접 표기된 고정된 값 자체(정수, 실수, 문자열, 불리언, null 등)를 의미합니다. 0 (정수 리터럴) 12.34 (실수 리터럴)"a" (문자열 리터럴) 0xff (16진수 정수 리터럴) ff: 따옴표가 없으므로 리터럴이 아닌 식별자(변수명/함수명 등)로 취급됩니다. null (Null 리터럴) false (불리언 리터럴) "hello" (문자열 리터럴) 4+5: 리터럴 간의 덧셈 연산이 포함된 식(Expression)입니다. 정답: ff, 4+5
