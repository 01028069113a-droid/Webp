14. 다음과 같이 변수 a, b가 선언되어 있을 때, 각 계산 후 a, b 값은 무엇인가? `let a="123", b="45"; | 식 | a | b | | :--- | :---: | :---: | | **(1) `a += b;`** | **`"12345"`** | **`"45"`** | | **(2) `a = parseInt(a) + parseInt(b);`** | **`168`** | **`"45"`** | | **(3) `a = 10 + a + b;`** | **`"1012345"`** | **`"45"`** | | **(4) `b = 10 + parseInt(a) + "ab";`** | **`"123"`** | **`"133ab"`** | 각 항별 풀이 과정 (1) `a += b;` 두 변수가 모두 문자열이므로 문자열 연결 연산이 일어납니다 (`"123" + "45"`). `a`는 12345, `b`는 45가 됩니다. (2) `a = parseInt(a) + parseInt(b); `parseInt("123")` $\rightarrow$ `123`, `parseInt("45")` $\rightarrow$ `45`로 숫자로 변환된 후 `123 + 45 = 168`이 계산됩니다. * `a`는 숫자 168, `b`는 45가 됩니다. (3) `a = 10 + a + b; * `10 + "123"` 연산 시 숫자가 문자열로 변환되어 10123이 되고, 거기에 + 45가 연산되어 1012345가 됩니다. a는 1012345, b는 45가 됩니다. (4) `b = 10 + parseInt(a) + "ab"; `10 + parseInt("123")` $\rightarrow$ `10 + 123` = `133` (숫자 덧셈) `133 + "ab"` $\rightarrow$ 숫자가 문자열로 결합되어 133ab가 됩니다. `a`는 123, b는 133ab가 됩니다
