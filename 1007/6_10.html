10. 다음 코드의 실행 결과 출력되는 내용은 무엇인가? (1) javascript let sum = 0; function acc() { let sum = 0; for(let i=0; i<10; i++) sum += i; } acc(); document.write("합 = " + sum); 풀이 과정 전역변수 `sum`이 `0`으로 초기화되어 있습니다. 함수 `acc()` 내부의 `let sum = 0;`은 지역변수 `sum`을 새로 생성하여 계산합니다. 따라서 함수 실행이 끝난 후에도 전역변수 `sum`은 변함없이 **`0`**입니다. * `document.write("합 = " + sum)`은 전역변수 `sum`의 값(`0`)을 출력합니다. 정답: **`합 = 0`** (2) javascript var sum = 0; function acc() { var sum = 0; for(let i=0; i<10; i++) this.sum += i; } acc(); document.write("합 = " + sum); 풀이 과정 전역 공간에서 `var sum = 0;`으로 선언하면 `sum`은 전역변수이자 `window.sum`(전역 객체의 프로퍼티)이 됩니다. * 일반 함수 호출 `acc()` 내부에서 `this`는 전역 객체(`window`)를 가리킵니다. * 따라서 `this.sum += i;`는 전역변수 `sum`에 `0`부터 `9`까지 더하게 되어, 전역 `sum`은 `0 + 1 + 2 + ... + 9 = 45`가 됩니다. 정답: 합 = 45
