2. 다음은 HTML 페이지와 브라우저의 출력 결과이다 자바스크립트 연습

자바스크립트란?

자바스크립트는 웹 프로그래밍 언어로서 웹 페이지를 동적 변경시킬 수 있다.

C 언어를 아는 사용자는 빠르게 학습할 수 있다.

이벤트 등 GUI 프로그래밍에 필요한 요소들이 있어 학습에 약간의 어려움이 있다.

정답: DOM 트리 구조 요약: > * -> ("자바스크립트 연습") > * <body> -> > * <h3> -> 텍스트("자바스크립트란? "), <button> ("border"), <button> ("p") > * <hr> > * <p> -> 텍스트("자바스크립트는 웹 프로그래밍 언어로서 웹 페이지를 동적 변경시킬 수 있다.") > * <p> -> <span> (id="mySpan", "C 언어"), 텍스트("를 아는 사용자는 빠르게 학습할 수 있다.") > * <p> -> 텍스트("이벤트 등 GUI 프로그래밍에 필요한 요소들이 있어 학습에 약간의 어려움이 있다.") (2)"border" 버튼을 클릭하면 다음과 같이 id="mySpan"인 태그에 2픽셀의 violet 색 점선 테두리가 생기도록 자바스크립트 코드를 작성하라. 정답: <button onclick="document.getElementById('mySpan').style.border='2px dotted violet';">border</button> (3) "p" 버튼을 클릭하면 <p> 태그가 몇 개 있는지 alert()를 통해 다음과 같이 출력되도록 자바스크립트 코드를 삽입하여 HTML 페이지를 수정하라. 정답: <button onclick="let pList = document.getElementsByTagName('p'); alert('<p> 태그의 개수는 ' + pList.length);">p</button>
