실습문제 1. 다음은 HTML 페이지와 브라우저의 출력 결과이다 라면을 끓이는 순서

라면을 끓이는 순서

  1. 물을 끓인다.
  2. 라면과 스프를 넣는다.
  3. 파를 썰어 넣는다.
  4. 5분 후 맛있게 먹는다.
(1) HTML 페이지의 HTML DOM 트리를 그려라 구조 요약: -> ("라면을 끓이는 순서") <body> -> <h3>, <hr>, <ol> (type="A") > <li> ("물을 끓인다.") > <li> ("라면과 스프를 넣는다.") > <li> ("파를 썰어 넣는다.") > <li> -> 텍스트("5분 후 "), <strong> ("맛있게"), 텍스트(" 먹는다.") (2) </ol>와 </body> 태그 사이에 다음과 같이 자바스크립트 코드를 작성하여 모든 <li> 태그를 찾아 글자 색을 green으로 출력하라. </ol> <script> // 이곳에 자바스크립트 코드를 작성하라. </script> </body> 정답: let list = document.getElementsByTagName("li"); for(let i=0; i<list.length; i++) { let item = list[i]; item.style.color = "green"; } (3) 리스트가 출력된 공간 아무 곳이나 클릭하면 리스트 전체의 배경색을 yellowgreen으로 바꾸는 자바스크립트 코드를 작성하라. 정답: <ol type="A" onclick="this.style.backgroundColor='yellowgreen'"> <li>물을 끓인다.</li> <li>라면과 스프를 넣는다.</li> <li>파를 썰어 넣는다.</li> <li>5분 후 <strong>맛있게</strong> 먹는다.</li> </ol>
